Deuce Windows x64
=================

실행 방법
---------

1. ZIP 파일을 로컬 폴더에 완전히 압축 해제합니다.
2. Deuce 폴더의 deuce_client.exe를 실행합니다.
3. 시스템 브라우저가 열리면 발급받은 Keycloak 계정으로 로그인합니다.

주의 사항
---------

- deuce_client.exe만 따로 복사하지 마십시오. data 폴더와 DLL이 모두 필요합니다.
- 서버, Keycloak 또는 Tailscale을 이 PC에 설치할 필요는 없습니다.
- 인터넷 연결과 기본 웹 브라우저가 필요합니다.
- 현재 빌드는 코드 서명되지 않았습니다. Windows SmartScreen이 경고하면 배포 파일의
  SHA-256을 관리자에게 확인한 뒤 실행하십시오.
- 계정과 비밀번호를 다른 사용자와 공유하지 마십시오.
