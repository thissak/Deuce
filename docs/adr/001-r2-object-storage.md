# ADR 001: Cloudflare R2를 파일 원본 저장소로 사용

## Status

Accepted

## Context

Deuce는 공개 인터넷에서 10명 이하가 사용하는 협업 도구이며, 대화 안에서 이미지,
영상, 일반 파일을 공유해야 한다. 애플리케이션 서버로 사용할 맥미니는 저장 용량이
제한적이므로 대용량 원본 파일을 로컬 디스크에 지속해서 보관하기 어렵다. 영상 탐색과
대용량 업로드를 지원하면서도 맥미니가 모든 파일 트래픽을 중계하지 않는 구조가 필요하다.

## Decision

- 이미지, 영상, 일반 파일의 원본을 비공개 Cloudflare R2 버킷에 저장한다.
- 애플리케이션 데이터베이스에는 R2 객체 키, 원본 파일명, 콘텐츠 유형, 크기,
  업로더와 메시지 연결 정보 등 파일 메타데이터만 저장한다.
- 애플리케이션 서버가 워크스페이스 권한을 확인한 뒤 짧은 유효기간의 서명 URL을
  발급하고, 클라이언트는 R2와 직접 업로드·다운로드한다.
- 버킷과 객체를 공개하지 않는다. 선택한 클라이언트 런타임이 브라우저 보안 모델을
  사용할 때만 필요한 CORS 출처를 최소 범위로 허용한다.
- 맥미니 로컬 디스크는 원본 파일의 영구 저장소로 사용하지 않는다.

## Consequences

- 맥미니의 저장 용량과 파일 전송 부하를 애플리케이션 처리에서 분리할 수 있다.
- 이미지 표시, 영상 재생, 대용량 파일 업로드를 애플리케이션 서버를 통하지 않고
  제공할 수 있다.
- R2 서비스 가용성과 비용 정책에 의존하며, 저장량과 요청량을 관찰해야 한다.
- 서명 URL은 만료 전까지 해당 객체에 접근할 수 있는 자격 증명이므로 짧게 유지하고
  로그나 메시지 본문에 보존하지 않아야 한다.
- 파일 보존 기간, 삭제 복구, 백업 정책은 별도의 운영 결정으로 남는다.

구체적인 연결 계약은 [R2 인프라 연결](../infrastructure/r2-connection.md)에 기록한다.
