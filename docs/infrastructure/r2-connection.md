# R2 인프라 연결

## 목적과 범위

Deuce는 Teams와 Slack을 참고한 PC·Android·iPhone용 설치형 협업 앱이다. 이 문서는
이미지, 영상, 일반 파일의 원본을 Cloudflare R2에 보관하기 위한 연결 경계와 보안
원칙을 정의한다.

현재 Cloudflare 사용 범위는 **비공개 R2 객체 저장소**뿐이다. 다음 항목은 이 문서의
범위에 포함하지 않는다.

- Cloudflare Access를 이용한 사용자 로그인
- Cloudflare Tunnel과 DNS를 이용한 맥미니 공개
- 웹사이트 또는 웹 클라이언트 호스팅
- 실시간 메시지 전송

사용자 인증, 역할과 채널 권한, 실시간 메시지는 Deuce 서버가 담당한다. 맥미니 서버를
공개 인터넷에 연결하는 방식과 클라이언트 구현 기술은 별도로 결정한다.

## 연결 구조

```text
PC / Android / iPhone 앱
        │
        │ 1. 인증된 파일 작업 요청
        ▼
Deuce 서버 (맥미니)
        │
        ├─ 사용자·채널 권한 확인
        ├─ 객체 키와 짧은 유효기간의 서명 URL 생성
        └─ 파일 메타데이터를 애플리케이션 DB에 기록
        │
        │ 2. 서명 URL 반환
        ▼
클라이언트 ── 3. 원본 직접 전송 ── Cloudflare R2 비공개 버킷
```

클라이언트는 R2 자격 증명을 갖지 않는다. Deuce 서버가 요청자의 권한을 먼저 확인한
뒤 특정 객체와 작업에만 유효한 서명 URL을 발급한다. 원본 바이트는 클라이언트와 R2
사이에서 직접 이동하며 맥미니에 영구 저장하지 않는다.

## 업로드 계약

1. 클라이언트가 파일명, 크기, 콘텐츠 유형과 연결할 대화 위치를 Deuce 서버에 보낸다.
2. 서버가 사용자와 채널 쓰기 권한, 파일 정책을 확인한다.
3. 서버가 추측하기 어려운 객체 키를 만들고 해당 객체에만 쓸 수 있는 서명 URL을
   발급한다.
4. 클라이언트가 원본을 R2로 직접 업로드한다.
5. 클라이언트가 완료를 서버에 알리면 서버가 R2의 객체 존재와 메타데이터를 확인한다.
6. 검증된 객체의 키, 원본 파일명, 크기, 콘텐츠 유형, 업로더와 메시지 연결 정보를
   애플리케이션 DB에 기록한다.

대용량 영상의 분할 업로드 방식과 적용 기준은 클라이언트 기술 스택을 선택한 뒤
결정한다.

## 조회 계약

1. 클라이언트가 파일 ID로 조회 또는 재생을 요청한다.
2. 서버가 사용자의 워크스페이스와 채널 읽기 권한을 확인한다.
3. 서버가 해당 R2 객체의 읽기 전용 서명 URL을 발급한다.
4. 클라이언트가 R2에서 파일을 직접 내려받거나 영상을 재생한다.

서명 URL 자체는 만료 전까지 접근 권한을 가진다. 메시지 본문, 영구 DB 필드와 로그에
URL을 저장하지 않고 요청할 때마다 새로 발급한다.

## R2 보안 원칙

- 버킷과 `r2.dev` 공개 접근을 활성화하지 않는다.
- 서버용 R2 API 토큰은 Deuce 전용 버킷의 Object Read & Write 권한으로 제한한다.
- 계정 ID, Access Key ID와 Secret Access Key는 맥미니의 서버 환경에만 둔다.
- R2 비밀값을 클라이언트 앱, Git 저장소, 로그와 오류 응답에 포함하지 않는다.
- 원본 파일명 대신 서버가 생성한 객체 키를 사용한다.
- 서명 URL은 객체, 작업과 유효기간을 최소 범위로 제한한다.
- 파일 삭제는 클라이언트가 R2에 직접 요청하지 않고 Deuce 서버의 권한 검사를 거친다.
- 선택한 클라이언트 런타임이 브라우저 또는 WebView 보안 모델을 사용할 때만 CORS를
  구성하고 필요한 출처·메서드·헤더만 허용한다.

## 서버 환경변수 계약

실제 값은 문서와 저장소에 기록하지 않는다. 애플리케이션은 다음 이름으로 서버 환경의
설정을 읽는다.

| 이름 | 용도 |
|---|---|
| `R2_ACCOUNT_ID` | Cloudflare 계정 식별자 |
| `R2_BUCKET_NAME` | Deuce 전용 비공개 버킷 이름 |
| `R2_ACCESS_KEY_ID` | 서버용 S3 호환 접근 키 |
| `R2_SECRET_ACCESS_KEY` | 서버용 S3 호환 비밀 키 |
| `R2_ENDPOINT` | 계정별 R2 S3 API 엔드포인트 |
| `R2_UPLOAD_URL_TTL_SECONDS` | 업로드 서명 URL 유효기간 |
| `R2_DOWNLOAD_URL_TTL_SECONDS` | 조회 서명 URL 유효기간 |

유효기간의 실제 기본값은 허용할 영상 크기와 모바일 네트워크 조건을 확인한 뒤 정한다.

## 연결 검증

인프라를 실제로 연결할 때 다음 항목을 모두 확인한다.

- 승인된 사용자는 PC·Android·iPhone에서 서명 URL을 받아 업로드할 수 있다.
- 권한 없는 사용자는 서버에서 거부되어 서명 URL을 받지 못한다.
- 업로드 완료 후 서버가 객체 크기와 콘텐츠 유형을 확인한다.
- 발급된 조회 URL로 이미지, 영상과 일반 파일을 가져올 수 있다.
- 만료되거나 변조된 URL은 R2에서 거부된다.
- 버킷 목록 조회와 공개 URL로는 원본에 접근할 수 없다.
- 맥미니를 재시작해도 비밀값이 저장소나 클라이언트에 노출되지 않고 연결이 복구된다.

## 남은 결정

- 맥미니 서버의 공개 인터넷 연결과 TLS 방식
- 사용자 인증, 세션과 역할 모델
- 허용할 파일 유형과 최대 크기
- 대용량 영상의 분할 업로드 기준
- 파일 보존 기간, 삭제 복구와 백업 정책
