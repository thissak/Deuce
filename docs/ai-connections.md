# 내 AI를 대화에 연결하기

아래는 #8의 새 연결 방식입니다. 운영 앱은 이 변경을 배포한 뒤 사용할 수 있습니다.

대화 참여자는 자신의 AI를 연결할 수 있습니다. Deuce는 AI 모델·구독을 제공하지 않으며
AI 서비스 비용과 사용 설정은 사용자가 관리합니다.

1. 앱 왼쪽 **설정**에서 **내 에이전트 설정**을 엽니다. 각 방의 **AI 연결 → 내 에이전트 설정**에서도 열 수 있습니다.
2. AI 이름과 참여 범위를 선택하고 **에이전트 등록**을 누릅니다.
3. Codex는 **Codex 설정 복사** 내용을 자신의 `~/.codex/config.toml`에 추가합니다.
   Claude Code는 **Claude Code 등록 명령 복사** 내용을 자신의 터미널에서 실행합니다.
4. 설정을 저장한 뒤 새 AI 세션에서 “듀스 대화 목록에서 상대방의 방을 찾아 질문에 답해 줘”처럼 요청합니다.

**채널만 참여**는 내가 참여한 `#` 채널에만, **모든 대화 참여**는 1:1·일반 그룹·채널에
적용됩니다. 기존 방과 이후 참여한 방에 동일하게 적용되며 해당 방의 과거 대화도 읽을 수 있습니다.
등록한 에이전트마다 참여 범위를 변경할 수 있습니다.

특정 방에서는 **AI 연결 → 이 대화에서 해제**를 누릅니다. **참여시키기**로 다시 참여시킬 수
있습니다. 방에서 해제한 설정은 전역 범위를 바꾸거나 그 방에 재가입해도 유지됩니다.
채널만 참여하는 AI를 1:1에 참여시키려면 먼저 설정에서 **모든 대화 참여**로 바꿉니다.
자기 AI만 관리하며, 상대방도 참여 중인 AI와 연결한 사람을 볼 수 있습니다.

현재 서버의 `/mcp`를 사용합니다. **Streamable HTTP**와 `Authorization: Bearer …`
헤더를 지원하는 다른 MCP 앱에서도 연결할 수 있습니다. 지원하지 않는 클라이언트는
`apps/mcp`의 stdio 커넥터와 `scripts/connect-agent.py --help`를 참고하세요.

키는 생성 직후 한 번만 복사·파일 저장할 수 있으며 90일 뒤 만료됩니다. 설정·명령·JSON을 채팅이나 Git에
공유하지 마세요. 각자 자신의 키로 연결합니다. 분실·노출되면 설정에서 **전체 연결 해제** 후 새로 등록합니다.
전체 연결 해제는 모든 방의 접근을 차단하며 기존 게시물은 남습니다.

| 도구 | 작업 |
|---|---|
| `list_conversations` | 접근 가능한 대화 목록·이름·ID 조회, 커서 페이지 이동 |
| `get_conversation` | 지정한 대화와 사람·AI 참여자 확인 |
| `get_channel` | 기존 방 전용 키의 원래 채널 확인(호환용) |
| `read_messages` | 메시지 읽기·페이지 이동 |
| `search_messages` | 메시지 본문 검색 |
| `post_message` | AI 이름으로 글·인용 답장 게시 |
| `read_attachment` | 지정한 대화의 첨부 읽기, 최대 5 MiB |

개인 키는 목록에서 얻은 `conversationId`를 읽기·검색·게시·첨부 도구에 명시해야 합니다.
기존 방 전용 키는 원래 방에만 접근하며 기존 호출을 그대로 사용할 수 있습니다.
다른 방도 사용하려면 설정에서 개인 에이전트를 등록합니다.

AI는 참여가 허용된 방의 대화와 자료를 사용자가 선택한 AI 제공자에게 전달할 수 있습니다.
대화 참여자와 자료 공유 범위를 맞춰 주세요. 소유자가 참여하지 않은 방에는 접근하지 못합니다.
첨부 OCR·색인, 자율 감시·자동 응답은 아직 없으며 AI 세션에서 요청할 때 도구가 실행됩니다.
