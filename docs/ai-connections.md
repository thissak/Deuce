# 대화하다가 내 AI 초대하기

아래 기능은 운영 웹과 데스크톱 0.2.0에 반영됐습니다. 기존 앱은 Deuce → 업데이트 확인에서
업데이트하거나 [다운로드](https://deuce.goldenlabs.dev/download)에서 설치하세요.
0.1.2에는 **이 PC에서 연결** 기능이 없습니다. 자체 서버는 새 코드와 migration을 함께 적용하세요.

대화 중 **AI 초대**를 누르면 기본 AI가 그 방에 참여합니다. 처음 한 번만 AI를 연결합니다.
초대된 뒤에는 다른 참여자도 **AI에게 요청** 또는 `@AI 이름`으로 질문할 수 있고,
답변은 같은 방에 AI 이름으로 표시됩니다.

## 처음 한 번: 데스크톱에서 연결

먼저 사용할 Codex CLI 또는 Claude Code를 PC에 설치하고 로그인합니다.
터미널에서 Codex는 `codex login`, Claude Code는 `claude auth login`을 사용합니다.
[Codex 안내](https://learn.chatgpt.com/docs/non-interactive-mode)와
[Claude Code 안내](https://code.claude.com/docs/en/headless)를 참고하세요.

1. 대화방의 **AI 초대**를 누릅니다. **설정 → 내 에이전트 설정**에서도 등록할 수 있습니다.
2. AI 이름을 정하고 **에이전트 등록**을 누릅니다. 기본 범위는 **초대한 방만 참여**입니다.
3. 사용할 **Codex / Claude Code**를 선택하고 **이 PC에서 연결**을 누릅니다.
4. 대화 중 연결을 시작했다면 연결 확인 후 원래 방에 자동으로 초대됩니다.

PC와 듀스 앱이 켜져 있어야 응답합니다. 연결한 PC에 로그인된 AI 서비스의 사용량을 사용합니다.
Deuce가 모델이나 구독을 제공하지 않습니다. 방의 다른 사람이 보내는 AI 요청도 이 사용량에 포함됩니다.

암호화 저장이 가능하면 다음 앱 실행 때 같은 Deuce 계정의 연결을 복구합니다.
저장이 불가능하면 현재 실행 동안만 연결하고 안내를 표시합니다. 로그아웃하면 실행기를 중단합니다.

## 이후에는 초대 버튼 한 번

- **AI 초대**: 기본 AI를 현재 방에 참여시킵니다. 다른 방은 별도로 초대합니다.
- **AI에게 요청**: 내용을 입력하거나 **지금까지 요약**을 선택합니다.
- 입력창에서 `@` 뒤 AI 이름을 선택하면 일반 메시지로도 요청할 수 있습니다.
- **내 AI 참여 중 / AI 관리 → 이 대화에서 해제**: 그 방 접근과 진행 중인 답변을 중단합니다.
  기존 답변은 남으며, 제공자에게 이미 전달된 자료를 회수하는 기능은 아닙니다.

여러 AI를 등록했다면 **내 에이전트 설정 → 기본 AI로 선택**으로 초대 버튼의 대상을 정합니다.
자기 AI만 초대·해제할 수 있고 다른 참여자는 AI 이름, 연결한 사람과 실행 상태를 볼 수 있습니다.

| 표시 | 의미 |
|---|---|
| 응답 가능 | PC 실행기가 서버에 연결됨 |
| 답변 중 | 진행 중인 요청이 있음. 한 AI에는 한 번에 하나만 요청 |
| 실행기 오프라인 | 연결된 PC에서 앱 또는 실행기를 켜야 함 |
| 접속 확인 | 연결 키로 서버에 접속한 이력. MCP 접속만으로 자동 답변이 켜지지는 않음 |

## 지금 AI가 읽는 범위

초대하면 해당 방의 과거·이후 대화와 자료에 접근할 수 있습니다. 자동 답변에는 **최근 대화 50개와
작은 텍스트 첨부**를 전달합니다. 삭제된 글과 시스템 공지는 제외합니다. 텍스트 파일은 하나당
32KB 이하, 한 요청에서 총 128KB 이하입니다. 긴 이전 대화 전체를 자동 요약하는 기능은 아닙니다.

현재 PC 실행기는 이미지/PDF 해석, 인터넷 조사, 로컬 파일 탐색을 하지 않습니다.
자료를 먼저 업로드한 뒤 별도 메시지에서 AI에게 요청하세요. 자동 감시·AI끼리의 자동 대화도 없습니다.
응답에 실패하면 안내가 남고 자동 재시도하지 않습니다. 같은 요청의 상태 확인/재전송은 중복 실행을 막습니다.

## 웹만 쓰는 경우

1. 같은 등록 화면에서 **연결 파일 저장 → AI 연결 파일 저장**을 누릅니다.
2. PC에 Deuce 저장소와 [개발 도구](getting-started.md)를 준비하고 `pnpm install --frozen-lockfile`을 실행합니다.
3. 해당 저장소의 터미널에서 저장한 파일 경로로 실행합니다.

```bash
pnpm --filter @deuce/agent-runner start /연결파일경로/deuce-connection.json codex
# Claude Code를 사용할 경우 마지막 인자를 claude로 변경
```

연결 후 듀스에서 서버 접속 확인 표시를 확인하고 **연결 설정을 저장했습니다**를 누릅니다.
대화에서 시작했다면 원래 방에 초대됩니다. 터미널을 켜 둡니다. `Ctrl+C`로 중단할 수 있습니다.
실행 검증 환경은 macOS의 Codex CLI 0.153.4와 Claude Code 2.1.263입니다.
다른 CLI 버전·Windows 실행은 추가 검증 대상이며 사용 중인 CLI가 비대화형 실행 옵션을 지원해야 합니다.

## 기존 MCP 연결 사용하기

등록 화면의 **기존 MCP 방식으로 연결**을 펼칩니다.
Codex는 **Codex 설정 복사** 내용을 자신의 `~/.codex/config.toml`에 추가하고,
Claude Code는 **Claude Code 등록 명령 복사** 내용을 터미널에서 실행합니다.
방에 초대한 뒤 새 AI 세션에서 “듀스 대화 목록을 확인하고 이 방 질문에 답해 줘”처럼 요청합니다.

서버의 `/mcp`는 Streamable HTTP와 `Authorization: Bearer …` 헤더를 지원합니다.
다른 MCP 앱에서도 사용할 수 있고 stdio가 필요하면 `apps/mcp`와 `scripts/connect-agent.py --help`를 참고합니다.
**MCP 설정만 등록한 AI는 듀스의 요청 버튼으로 자동 실행되지 않습니다.** 외부 AI 앱에서 직접 요청하거나
위의 PC 실행기를 함께 연결해야 합니다.

| MCP 도구 | 작업 |
|---|---|
| `list_conversations` | 접근 가능한 대화 목록·이름·ID 조회 |
| `get_conversation` | 지정한 대화와 사람·AI 참여자 확인 |
| `get_channel` | 기존 방 전용 키의 원래 채널 확인 |
| `read_messages` | 메시지 읽기·페이지 이동 |
| `search_messages` | 메시지 본문 검색 |
| `post_message` | AI 이름으로 글·인용 답장 게시 |
| `read_attachment` | 지정한 대화의 첨부 읽기, 최대 5 MiB |

개인 키는 읽기·검색·게시·첨부 도구에 `conversationId`를 명시합니다.
기존 방 전용 키는 원래 방에만 접근하며 기존 호출을 그대로 사용할 수 있습니다.

## 기존 범위와 키 관리

기존 **채널만 참여**와 **모든 대화 참여** 연결은 기존 방과 새 방에 계속 적용됩니다.
필요할 때만 초대하려면 범위를 **초대한 방만 참여**로 바꾼 뒤 각 방에서 초대하세요.
소유자가 참여하지 않은 방에는 접근하지 못합니다. 특정 방에서 해제한 설정은 범위 변경에도 유지됩니다.

키는 발급 직후 한 번만 저장할 수 있고 90일 뒤 만료됩니다. 연결 파일·설정·명령에는 비밀 키가 있으므로
채팅이나 Git에 공유하지 마세요. 분실·노출·만료 시 **전체 연결 해제** 후 새로 등록합니다.
전체 해제는 모든 방의 접근을 차단하며 기존 게시물은 남습니다.

공식 MCP 안내: [Codex](https://learn.chatgpt.com/docs/extend/mcp?surface=cli),
[Claude Code](https://code.claude.com/docs/en/mcp).
