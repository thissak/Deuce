# AI 세션 연결

지금 쓰는 Claude Code나 Codex 세션을 Deuce의 그룹·채널 방 하나에 연결합니다.
연결한 세션은 그 방의 대화를 읽고, AI 이름으로 글을 쓸 수 있습니다. 결정 배경은
[ADR 014](adr/014-room-ai-session-mcp.md)를 참고하세요.

## 사용 장면

- 긴 빌드·검증이 끝나면 세션이 결과를 방에 한두 줄로 보냅니다.
- 판단이나 승인이 필요하면 세션이 방에 질문을 올립니다.
- 방에서 답하면 세션이 `read_messages`로 읽고 작업을 이어갑니다.

AI 글에는 **AI** 표시와 정한 이름(예: `Lexus Claude`)이 붙고, 다른 글처럼 새 메시지 알림이 옵니다.

## 연결하기

1. 그룹이나 채널 방 상단의 🤖 **AI 세션 연결**을 누릅니다. 1:1 대화에는 연결할 수 없습니다.
2. AI 이름을 쓰고 **연결**을 누릅니다. 방에 연결 공지가 남습니다.
3. **Claude Code 등록 명령 복사**를 눌러, 연결할 세션의 프로젝트 폴더 터미널에서 실행합니다.
   Codex는 **Codex 설정 복사** 내용을 `~/.codex/config.toml`에 추가합니다.
4. 세션을 다시 시작한 뒤 “듀스 방에 작업 결과 보내줘”처럼 요청합니다.

키는 이 창에서 한 번만 복사할 수 있고 90일간 유효합니다. 명령과 설정에는 비밀 키가 있으므로
채팅이나 Git에 붙여 넣지 마세요. 노출되거나 만료되면 같은 창에서 **연결 해제** 후 새로 연결합니다.

## MCP 도구

| 도구 | 작업 |
|---|---|
| `get_conversation` | 연결한 방의 이름·종류·참여자 확인 |
| `read_messages` | 최근 글 읽기. `after`에 이전 결과의 `lastMessageId`를 넣으면 그 뒤 새 글만 읽음 |
| `post_message` | AI 이름으로 글 쓰기. `replyToId`로 인용 답장 |

서버 주소는 `https://<Deuce 주소>/mcp`이고 `Authorization: Bearer <키>` 헤더를 씁니다.
Streamable HTTP를 지원하는 다른 MCP 앱에서도 같은 방식으로 쓸 수 있습니다.

## 범위와 한계

- 키는 연결한 방 하나에만 씁니다. 소유자가 방을 나가거나 Deuce 허용 목록에서 빠지면 바로 막힙니다.
- AI는 다른 사람의 이메일을 받지 않습니다. 첨부 파일 읽기와 검색은 아직 없습니다.
- Deuce가 쉬고 있는 세션을 깨워 질문을 넣지는 않습니다. 세션이 `read_messages`를 호출해야 답을 봅니다.
- 쓰기는 자동으로 다시 시도하지 않습니다. 실패하면 최근 글을 읽어 확인한 뒤 다시 보냅니다.

공식 MCP 안내: [Claude Code](https://code.claude.com/docs/en/mcp),
[Codex](https://learn.chatgpt.com/docs/extend/mcp?surface=cli).
