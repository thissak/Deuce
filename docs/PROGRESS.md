## 수동 검증 대기 (Google OAuth 클라이언트 발급 후)

계획 ④ 산출물은 실 브라우저 검증이 남아 있다. 계획 ⑤ 착수 전에 감독과 함께
`pnpm --filter @deuce/server dev` + `pnpm --filter @deuce/web dev`로 확인한다.

- [ ] Google 로그인 — 허용 계정 성공, 비허용 계정 403
- [ ] 브라우저 2개(서로 다른 허용 계정)에서 메시지·답장·수정·삭제·반응·고정이
  새로고침 없이 상대 화면에 반영
- [ ] 다른 방을 보는 중 수신 시 목록 배지 증가 → 방 진입 시 해소, 탭 숨김 시
  자리 비움 점 → 포커스 복귀 시 온라인
- [ ] 파일 첨부(캡션 포함) 전송 → 첨부 카드 → 공유 탭 → 다운로드
- [ ] 한국어 키워드 검색 → 결과 클릭 시 해당 방 이동·하이라이트, 활동 탭의
  멘션·반응 항목 클릭 점프
- [ ] 탭 숨김 상태 수신 시 웹 알림 표시, 클릭 시 해당 방 이동, 음소거 방은
  알림 없음
- [ ] 타임라인 스크롤 3종 — ①"이전 메시지 보기"로 과거를 불러와도 화면 위치
  유지 ②상단(과거)을 읽는 중 새 메시지가 와도 하단으로 튀지 않음 ③하단에
  있을 때는 새 메시지를 자동 추종. jsdom은 레이아웃을 계산하지 않아 자동
  검증이 불가능하다 (T6 리뷰 판정)
