# AI 참여 재설계 계획

작성: 2026-09-11 · 상태: 검토 초안, 신규 AI 구현 전 · [이슈 #18](../issues/18-reset-ai-feature.md)

## 출발점

감독의 질문은 “지금 이야기하는 AI가 채널에 들어갈 수 있는가”, “다른 사용자는 내 봇과 어떻게 이야기하는가”였다.
기존 초대 구현은 별도 CLI 작업을 실행했으므로 현재 대화 세션을 공유한다는 기대와 달랐다.
우선 기존 AI UI·API·MCP·실행기를 제거하고 사람 채팅을 기준 상태로 삼는다.
과거 AI 답변은 작성자와 함께 읽을 수 있게 보존한다. 제거 배포는 별도 후속 작업이다.

## 먼저 결정할 사용자 경험

| 후보 | 연결하는 대상 | 채널 참여자가 기대하는 행동 | 확인할 문제 |
|---|---|---|---|
| 현재 작업 세션 공유 | 소유자가 지금 사용하는 특정 대화 | 같은 맥락으로 질문하고 답변 받기 | 기존 대화 공개 범위, 동시 입력, 소유권, 연결 가능성 |
| 채널 전용 봇 | 채널용으로 새로 시작한 대화 | 채널 맥락을 이어서 답하기 | 실행 장소, 비용 부담, 소유자 부재 때 동작 |

현재 작업 세션 공유를 우선 검토하는 것이 질문에 가깝다. **선택이 확정되지는 않았다.**
두 방식을 같은 “초대” 버튼 아래 섞지 않는다. 지원 가능성을 확인하기 전에는 현재 세션에
접속할 수 있다고 약속하지 않는다. 기존 9월 8일 영속 세션 초안은 참고 자료이며 구현 지시는 보류한다.

## 제안 흐름 (선택 후 구체화)

1. 소유자가 연결할 대화와 대상 채널을 선택한다. 과거 대화를 공유할지, 연결 이후만 공유할지 명시한다.
2. 확인 화면에 AI 표시 이름, 소유자, 실제 연결 대상, 채널에 공개될 범위와 사용량 부담 주체를 보여준다.
3. 채널 참여자는 연결 대상과 현재 응답 가능 여부를 확인하고 이름을 멘션해 요청한다.
4. 질문마다 처리 중·완료·실패를 구분한다. 중복 제출과 재연결이 두 번 실행되지 않아야 한다.
5. 소유자가 해제하면 새 요청을 중단한다. 진행 중 요청의 취소 결과를 표시하고 게시된 대화는 남긴다.

단순히 방 접근 권한이 있다는 이유로 “응답 가능”을 표시하지 않는다. 오프라인·연결 해제·실행 실패는
사용자가 다음 행동을 선택할 수 있는 말로 구분한다. 채널 밖 파일이나 개인 대화의 자동 공개는 기본 동작에 넣지 않는다.

## 단계와 완료 기준

### 1. 사용 흐름 선택

두 후보의 연결→질문→해제 화면 흐름을 비교해 한 가지 MVP를 선택한다.
소유자·다른 참여자의 권한, 과거 맥락 범위, 사용량 부담, 소유자 부재 정책을 문서에서 결정한다.
완료 기준: 각 항목에 미정 표시가 없고 감독이 하나의 흐름을 선택했다.

### 2. 기술 가능성 실험

선택한 흐름을 공식 지원 인터페이스와 합성 대화로 실험한다. 실제 개인 세션이나 운영 채널을 실험 데이터로 쓰지 않는다.
세션 식별·대화 유지·동시 입력·중단·재접속·접근 회수 가능 여부를 기록한다.
완료 기준: 정상 연결과 재시작, 연결 불가와 권한 회수 시나리오를 재현하고 가능/불가능을 판정했다.
불가능한 계약은 화면 약속부터 수정하고 구현을 시작한다.

### 3. 최소 구현과 검증

한 공급자·한 연결 방식부터 구현한다. 자동 감시, 여러 실행기 자동 선택, 범위 전체 초대는 후속 검토한다.
아래 6개를 모두 통과해야 배포 후보로 삼는다.

- 소유자와 다른 참여자가 같은 연결 대상·공개 범위를 식별한다.
- 정상 질문은 해당 채널에 정확히 한 번 답하고 대화 맥락을 계약대로 유지한다.
- 개인 대화·다른 채널의 맥락은 승인된 범위 밖으로 공개되지 않는다.
- 동시 요청·재시도·재시작 후에도 요청과 답변의 대응이 유지된다.
- 오프라인·실패·해제 시 거짓 응답 가능 표시가 없고 새 실행이 거부된다.
- 사람 채팅·멘션·파일·알림 및 과거 AI 기록의 회귀 검증을 통과한다.

## 이번 작업의 경계

기존 코드 제거와 위 계획 작성까지 진행했다. 새 AI 모델·API·실행기를 만들거나 운영 배포하지 않았다.
기존 DB 모델은 기록 보존용이며 새 설계의 기본 모델로 재사용하기로 결정한 것이 아니다.
