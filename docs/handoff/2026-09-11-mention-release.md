# 멘션 표시·키보드 선택 — 0.2.3

## 완료된 작업

- 전송된 메시지에서 멘션은 `@` 없이 이름만 기존 강조 색상으로 표시한다. 입력창의 평문 `@이름`과 저장 본문·멘션 ID·AI 실행 계약은 유지한다.
- `@` 후보 목록은 첫 항목 선택, ↑↓ 순환 이동, Enter 선택, Esc 닫기를 지원한다. 활성 후보를 강조하고 스크롤하며 입력창 포커스를 유지한다. 한글 조합 중 Enter는 선택·전송하지 않는다.
- 웹 162·서버 94·데스크톱 15·MCP 2·실행기 6개(총 279개) 테스트와 전체 타입 검사·빌드 통과. 서버는 운영 VM의 별도 임시 DB에서 실행하고 해당 DB를 제거했다. 운영 DB 변경은 없다.
- 합성 데이터와 실제 Composer·CSS를 사용한 Chromium에서 방향키 선택·목록 스크롤·Esc·이름만 표시·계산된 강조 색상·브라우저 오류 없음을 확인했다.
- 운영 웹 `20260911-01`과 Mac arm64/x64·Windows x64 `0.2.3`, 다운로드 페이지와 두 업데이트 피드를 공개했다. 운영 백업 성공·health 정상·Deuce 및 기존 서비스 active를 확인했다.
- 세 패키지의 버전과 main/preload 바이트가 빌드와 일치한다. 피드가 참조하는 5개 파일의 SHA-512·크기와 스테이징 파일 SHA-256을 확인했다.
- Mac 두 앱의 Developer ID 서명·Apple 공증·staple·Gatekeeper·DMG 검증을 통과했다. 공증 ID: x64 `f11f319c-f30f-4766-833a-add7d1b0a79d`, arm64 `fdd334fe-327b-4d6e-adbb-f2622cd98398`.
- 서버·MCP·공용 계약 파일 해시는 이전 운영 릴리스와 같다. 배포 소스 285개 파일의 해시를 VM `DEPLOYMENT.json`에 기록했다. 미커밋 소스 스냅샷이며 별도 대화 유지 계획 문서는 배포하지 않았다.
- 이전 웹 `20260910-02`와 데스크톱 `0.2.2` 및 과거 설치 파일 URL을 보존했다. 비공개 GCS에 서버·설치 파일을 보관했고 서버 복구본은 재다운로드 SHA-256 일치를 확인했다.

- 공개 HTTPS 경로에서 웹 자산·설치 파일 58개를 VM에서 전체 다운로드해 SHA-256 일치를 확인했다. health·SPA·인증 401·비밀/없는 자산 404 등 HTTP 점검 6개 통과. 로컬에서도 두 피드·작은 파일 전체 해시와 큰 설치 파일 5개의 Range 206·크기·앞부분 바이트를 확인했다. 로컬의 대형 DMG 2개 전체 다운로드는 180초 제한에 걸려 VM 공개 경로 검증으로 보완했다.

## 다음 확인

- 설치 앱의 실제 0.2.2→0.2.3 업데이트·멘션 사용 확인은 사용자 환경에서 진행한다. 사용자 앱 강제 재시작·교체는 수행하지 않았다.
- 앱의 Deuce → 업데이트 확인 → 다운로드 → 재시작하고 설치로 업데이트한다.
