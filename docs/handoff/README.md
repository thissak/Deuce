# 개발·검증 기록

Markdown은 구현과 검증 결과의 공개 기록입니다. 2026-09-08 공개 개발 준비 과정에서
개인 경로와 운영 식별자를 예시로 바꿨습니다. `YOUR_*`는 실제 리소스가 아닙니다.

`*-receipt.json`은 로컬 운영 증빙이며 Git에서 제외됩니다. 해당 파일 참조는
유지관리자의 비공개 증빙을 뜻합니다. 공개 소스에는 이 파일이나 운영 데이터가 없습니다.
외부 기여자는 CI와 로컬 테스트로 검증합니다.

운영자용 원본 Markdown은 `.private/oss-preparation/originals/`에 보존했습니다.
