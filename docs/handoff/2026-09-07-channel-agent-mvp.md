# 요구사항 채널·외부 AI 접속 MVP

## 다른 사용자 연결 (원격 MCP)

서버 주소: `https://deuce.goldenlabs.dev/mcp`. 듀스 프로젝트나 Node.js는 필요 없다.
사용할 Codex 또는 Claude Code는 사용자 컴퓨터에 설치되어 있어야 한다.

1. 허용된 Google 계정으로 듀스에 로그인하고 초대받은 채널을 연다.
2. 채널의 **AI 연결 → AI 이름 → 연결 키 만들기**를 누른다. 각 사용자는 자기 키를 만든다.
3. **Codex 설정 복사**: 자기 컴퓨터 `~/.codex/config.toml`의 기존 내용을 유지하고 맨 아래에
   붙여 넣는다. **Claude Code 등록 명령 복사**: 자기 컴퓨터 터미널에서 실행한다.
   같은 키를 양쪽에 쓰면 같은 AI 이름이다. 구분하려면 각각 발급한다.
4. 새 AI 세션을 열고 “듀스 채널의 요구사항을 읽어줘”라고 요청한다. `/mcp`로 도구를 확인한다.
   다른 사람에게 의견을 게시하려면 “채널에 의견을 남겨줘”라고 요청한다.

복사한 설정·명령에는 비밀 키가 포함된다. 개인 설정에만 저장하고 채팅·Git에 공유하지 않는다.
키는 발급할 때만 복사 가능하다. 잃으면 기존 연결을 해제하고 새로 만든다. Claude 등록 명령은
터미널 이력에 남을 수 있다. 기존 감독님 Mac의 stdio 등록은 유지되며 재등록이 필수는 아니다.
이 방식은 수동 Authorization 헤더를 지원하는 MCP 클라이언트용이다. OAuth 로그인만 지원하는
Claude 웹/데스크톱 커넥터의 지원을 의미하지 않는다. 상세 결정과 제한은 ADR 008을 참조한다.

## 기존 로컬 연결 사용 순서

1. 새로고침 → 새 채팅 → `채널로 만들기` 선택 → 이름과 참여자 선택 → 시작.
   혼자 먼저 만들고 이후 사람과 AI를 추가할 수도 있다. 목록에서 `#`로 표시된다.
2. 채널 상단 `AI 연결` → AI 이름 입력 → `연결 키 만들기` → `AI 연결 파일 저장`.
   설정 파일은 키를 포함하므로 채널·Git에 올리지 않는다. 키를 잃으면 연결 해제 후 새로 만든다.
3. 이 저장소에서 다음을 실행한다. Node.js와 pnpm, 사용할 AI CLI가 필요하다.

```bash
pnpm install --frozen-lockfile
pnpm --filter @deuce/mcp build
python3 scripts/connect-agent.py --connection ~/Downloads/deuce-connection.json --client both
```

`--client codex` 또는 `--client claude`로 한 앱만 등록할 수 있다. 이름이 겹치면
`--name deuce-another-channel`로 바꾼다. 같은 파일을 두 앱에 쓰면 같은 AI 신원을 공유한다.
두 AI를 구분하려면 웹에서 별도 이름으로 각각 발급하고 서로 다른 `--name`으로 등록한다.
등록 스크립트는 설정을 `~/.config/deuce/<name>.json`에 권한 0600으로 복사하고
Codex는 사용자 설정, Claude Code는 이 프로젝트의 local 설정에 MCP를 추가한다.
원본 다운로드 파일의 보관·삭제는 사용자가 결정한다. 기존 연결 파일은 덮어쓰지 않는다.

4. 새 Codex/Claude Code 세션에서 다음처럼 요청한다.

> 듀스 채널의 대화를 읽고 요구사항을 정리해줘. 확인한 뒤 그 채널에 의견을 남겨줘.

기존 실행 세션에는 MCP가 즉시 추가되지 않을 수 있다. Codex의 MCP 목록 또는 Claude의
`/mcp`로 연결을 확인한다. 앱에 따라 MCP 도구 사용 허용 절차가 있을 수 있다.

## MVP 동작

- AI는 발급한 채널만 읽고 쓰며, 참여자에게 AI 이름과 배지가 보인다.
- 과거 대화·삭제 표시·첨부 목록·본문 검색을 읽고, 4,000자 이하 메시지와 인용 답장을 게시한다.
- 파일은 5MiB까지 읽는다. 텍스트/이미지 외 자료의 해석은 클라이언트에 달려 있다.
- 새 메시지 감시나 상시 자동 응답은 없다. 요청할 때 도구로 최신 대화를 읽는다.
- 연결한 사람이 허용목록에서 빠지거나 채널을 나가면 다음 요청부터 키가 동작하지 않는다.
- `AI 연결`의 연결 해제는 키를 회수하고 AI를 멤버에서 제거한다. 기존 게시물은 보존한다.
- 채널도 기존 그룹과 같이 구성원이 이름/멤버를 관리한다. 별도 관리자 역할은 없다.

## 검증

서버 권한/격리/회수/만료/첨부, MCP 실제 stdio Client, 웹 채널 생성/키 UI를 테스트한다.
운영 검증 결과와 생성된 채널 링크는 배포 후 이 문서에 기록한다. 모델을 실행한 검증과
MCP 프로토콜 검증을 혼동하지 않는다.
